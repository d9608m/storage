# Collection Of KQL Queries
A collection of Kusto Query Language (KQL) queries for use with Microsoft Sentinel, Microsoft Defender XDR Advanced Hunting, Azure Monitor / Log Analytics and Azure Data Explorer.

## Structure
- Each query lives in its own `.kql` file with a descriptive name (e.g., `failed-signins-by-user.kql`).
- Start each file with a short comment block covering what the query does, the data source/table it needs, and any parameters to adjust.
